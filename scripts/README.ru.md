# Скрипты репозитория

Запускайте скрипты через корневой [package.json](../package.json). Прямой запуск нужен только для диагностики конкретного этапа сборки.

- `build/` собирает HTML, компилирует и упаковывает ресурсы приложения, генерирует контракты, собирает изолированное демо и готовит файлы для хостинга.
- `checks/` выполняет smoke-проверки и проверяет собранные файлы для хостинга.
- `dev/` запускает Express с отслеживанием изменений для разработки.

`npm run build` создаёт локальные результаты сборки и ничего не развёртывает. Генерируемые файлы нужно пересобирать из исходников. Настройка, выходные каталоги и команды проверок описаны в [руководстве по разработке](../docs/development.ru.md).
