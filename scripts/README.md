# Служебные сценарии

- `build/` — очистка generated output, сборка клиента, BIM-viewer, hosting
  surface и статической инфоленты.
- `checks/` — smoke-тесты и проверки собранных артефактов.
- `dev/` — локальный запуск и watch-режимы для разработки.

Запускайте сценарии через команды из корневого `package.json`. Прямой запуск
нужен только для диагностики конкретного этапа.
