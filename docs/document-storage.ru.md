# Защищённая исполнительная документация

[English](document-storage.md)

Метаданные версий PDF хранятся в Firestore по пути `projects/{projectId}/documents/{documentId}/versions/{versionId}`, файлы — неизменяемыми объектами Cloud Storage. Запись `documentMembers/{uid}` даёт доступ читателя или редактора только к документам. Права назначает владелец объекта; доступа к исходным проверкам и настройкам объекта они не предоставляют. Версия связывается с конструкцией, сохранённой проверкой и BIM-элементом. Ссылка на отсутствующую проверку выбранного объекта отклоняется.

Для существующего авторизованного API необходимо настроить `FIREBASE_STORAGE_BUCKET` и Admin-доступ к нужному проекту. Хранилище должно быть закрытым, с запретом публичного доступа. При отдельном размещении API задайте `window.__APP_CONFIG__.DOCUMENT_API_BASE` до запуска приложения и добавьте origin приложения в существующий `ALLOWED_ORIGINS` API. Иначе запросы документов идут на origin приложения. Развёртывание и настройка хранилища выполняются оператором отдельно; эти изменения их не запускают.

Клиент создаёт только незавершённые метаданные; запись файла и перевод версии в готовое состояние доступны API. Он проверяет пользователя, права владельца/редактора, размер (до 20 МиБ), сигнатуру/конец PDF, SHA-256 и неизменяемый адрес объекта. Условие поколения запрещает перезапись. В транзакции завершения права проверяются повторно. Сбой оставляет видимую незавершённую версию; прерванное завершение можно повторить. Новая загрузка всегда получает новый ID версии, прежние сохраняются.

Файлы загружаются и скачиваются через API: клиентские Storage endpoints Firebase могут создавать постоянные download tokens. Signed URLs и Firebase download URLs не создаются. При скачивании повторно проверяются права и целостность файла; ответ передаётся как вложение с `private, no-store` и исключён из кеша service worker. Отзыв прав блокирует новые запросы, но не удаляет уже скачанный участником файл. `storage.rules` запрещает прямой клиентский доступ; Admin-доступ API отдельно проверяет те же права.

Проверка сигнатуры PDF не оценивает инженерное содержание и не подтверждает лабораторное заключение. Для приёмки бетона нужно отдельно подтверждённое основание. Исходные инженерные записи, их ID и исторические статусы не мигрируются и не перезаписываются.

Проверка: `npm run test:documents` запускает локальные эмуляторы Firestore/Storage с проектом `demo-`. Публичная демоверсия не подключается к хранилищу. Автоматического удаления версий и незавершённых попыток нет. Резервировать следует метаданные и файлы вместе. Откат приложения не требует удаления документов или проверок; закрытые правила Storage необходимо сохранить.
