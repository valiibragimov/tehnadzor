# UX/UI-ревизия Tehnadzor

[Русский](ux-ui-revision.ru.md) | [English](ux-ui-revision.md)

База: `44d96e647b01744a4d549cdf8059a0e9cfddd0fb`.

## Объём

Улучшить существующий интерфейс, прежде всего Геодезию, Армирование, Геометрию и Прочность бетона. Использовать существующие компоненты и слой `design`; сохранить ID, контракты событий, расчёты, нормативные значения, права, бизнес-логику и данные. Без новых зависимостей и развёртывания.

- Единые размеры полей, отступы, заголовки и пары «проект / факт».
- На desktop параметры идут первыми, сохранённые проверки — рядом. Сохранить мобильные шаги и нативные диалоги. Проверка и очистка формы находятся у ввода; удаление списка — у сохранённых записей.
- Ограничить вертикальное изменение textarea и переносить длинный текст.
- Сохранить нативные значения select и обработчики. Раскрывать обрезанное выбранное название через общий popover с управлением клавиатурой; сохранить RU/EN.
- Исправить аналогичные переполнения, контраст, поля даты и checkbox на остальных страницах. Сохранить переименование объектов. Обеспечить доступ к существующей документации через мобильную и свёрнутую навигацию.

## Зафиксированные проблемы

1. Контекст объекта: название конструкции обрезалось без раскрытия; язык мог обрезаться в компактном header. Исправлены границы select и добавлена кнопка полного названия.
2. Ввод: несогласованные вложенные подписи/fieldset, удалённые от формы действия и смещённые пары координат. Исправлены общий слой дизайна и исходные HTML partials.
3. Основания/комментарии: неограниченное изменение размеров, слабый контраст сохранённых значений и сегментов даты. Ограничены размеры и применены семантические цвета тем.
4. Остальные поверхности: слишком высокий демобаннер на узких экранах и недоступное меню проверок при 761–768 px. Исправлены flex-размеры и breakpoint.

Снимки — локальные материалы ревью в `output/playwright/ux/`, не исходные ресурсы. Исходные снимки получены в локальном синтетическом demo; реальные авторизованные данные не использовались.

## Проверка

Ширины браузера: 320, 390, 768, 1024 и 1440 px; светлая/тёмная темы, reduced motion. Проверяются границы, пары полей, действия, полное название с клавиатуры/Escape, неизменность выбранного объекта и сохранённых данных, ограничения textarea и значения после повторного открытия диалога. Существующие UI-сценарии покрывают динамические строки конструкций, BIM, сохранение, другие страницы и RU/EN. Проверка доступности целевая; формальная сертификация WCAG не проводится.
